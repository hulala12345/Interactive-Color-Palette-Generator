# Interactive Color Palette Generator

This project is a small web tool for generating harmonious color palettes.

## Features
- Pick a base color via color input or hex code.
- Generate complementary, analogous, triadic, tetradic and monochromatic schemes.
- Preview how the colors look on simple UI elements.
- Export generated palette as CSS variables, SCSS, JSON or SVG.

Open `index.html` in a browser to start using the tool.
